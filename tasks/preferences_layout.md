# Preferences

## Appearance
- Choose theme (auto/light/dark)
- Choose color (default, [saved list items])
  - Add new color (color picker, hex field)
  - Name the color (save button)
- Background pattern

## Tags
- New tag input field
- List of tags with color choices

## Defaults
- starting view for tasks
- priority for tasks
- reminder before due
### reminder for recurring tasks
- daily
- weekly
- monthly
- yearly

## Advanced
- Show Archived tab
- Show Cancelled tab
- Show number badge next to priority icons
- Completed tasks archive automatically after
- Show hint examples below task input box
- Show task age across views
- Keep filter panel open
